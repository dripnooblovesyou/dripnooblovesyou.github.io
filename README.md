# dripnooblovesyou.github.io

Static LakeMUN website for GitHub Pages.

## Editing
- Edit root HTML files: `index.html`, `about.html`, `conference.html`, `committees.html`, `registration.html`, `resources.html`, `contact.html`.
- Assets live in `static/` (`static/css`, `static/js`, `static/images`, PDFs in `static/resources` and `static/background guides`).

## Deployment
- Push to GitHub and enable GitHub Pages for this repository.
- Keep `CNAME` in the repo root if using the custom domain.
